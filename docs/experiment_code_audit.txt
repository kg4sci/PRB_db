1. 推理流程
当前 Final 主实验仍是 single-stage：system prompt 和 user prompt 在一次
请求中送入模型，user prompt 同时包含候选期刊；“先判断再看候选”由提示词要求。
OpenAI-compatible 主入口：
  LLM_code/inference/Final/inference_single_stage.py
  LLM_code/inference/Final/inference_single_stage_CoT.py
Anthropic-compatible 主入口及依赖：
  LLM_code/inference/Final/Anthropic/inference_single_stage.py
  LLM_code/inference/Final/Anthropic/inference_single_stage_CoT.py
  LLM_code/inference/Final/Anthropic/anthropic_inference_common.py
这些入口与论文中“在看到候选列表之前完成分诊”的严格信息隔离并不等价。
Old/inference_two_stage.py 是历史实现，不应仅凭文件名作为本论文结果入口发布。
GitHub Direct 与 Final Direct 的 system/user prompt 函数 AST 一致；
API 调用核心一致，异常日志存在差异。

3. 42 份结果的实例校验
主实验 8 + no_metrics 8 + only_name 8 + keyword_noised 8
  + synthetic_degradation 8 + GPT send90hint 2 = 42。
合计 218,760 条结果。各运行均按对应数据集的 uid/data_type/subject/target
复合键核对：缺失 0、未知实例 0、重复 0。
使用 GitHub 当前评测器离线重算八组主实验，Accuracy、Macro-F1、Q-F1、
R-F1、Joint、MRR、NDCG@5 共 56 个数值，全部与论文三位小数结果一致。
证据保存在 output/code_release_audit/main_metrics_check.json。
部分主实验/消融/先验结果保留旧标签 Lack of Novelty/Impact；仅将该标签
规范化为 Insufficient Novelty/Impact 后，所有结果的 ground_truth 均匹配。
逐运行覆盖、错误数、原始及规范化标签差异见 configs/paper_experiments.json。

4. 错误记录与重试策略
42 份结果共保留 339 条 Error/非字典响应记录，不能把“覆盖完整”写成
“全部输出有效”。主实验包括 Claude 39/41、DeepSeek 3/2、Qwen 4/26 条
错误记录（依次为 Direct/Rationale-first），GPT 主实验两组均为 0。
原始结果应保留；历史复现不应静默剔除错误记录或重试后覆盖论文结果。
Final 的 Anthropic 与冻结扰动入口有 schema 校验和输出修复重试，基础
OpenAI-compatible 主入口与 GitHub 主入口主要处理 API 重试，不能写成统一策略。
当前源码默认：API 最多 3 次尝试；支持输出修复的入口默认最多 4 次输出尝试；
Anthropic-compatible 默认 max_tokens=2048。这些默认值可由环境覆盖，
缺少历史启动环境时，不能声称所有论文运行必然使用这些默认值。

7. 论文补充实验的选择
主表 baseline 应对应：
  run_logreg_no_source_jcrq.py：5-fold GroupKFold，按论文 uid 分组，TF-IDF
    在训练折内拟合，包含目标 JCR quartile，排除源期刊、SSI 与 transfer gold。
  run_lexical_full_profile_baselines.py：Jaccard / BM25 使用完整期刊 profile。
  run_embedding_profile_baseline.py：SciBERT FullProfile / mean pooling / 512；
    SPECTER Scope / CLS pooling / 512。不要用 centroid-128 变体替代论文结果。
补充依赖：scikit-learn（分类/词法基线），torch、transformers（向量基线）。
现有 requirements.txt 未覆盖这些新增基线依赖，本轮未更改。
专家验证数据中 annotation 与 label-review 文件用途不同，最终统计应对应
论文的 200 个盲评样本，不应把多种中间文件简单拼接计算。
